# Hush

Минимальный мессенджер: email+пароль регистрация с кодом на почту, аватары,
поиск людей, личные чаты, группы и каналы, реальное время через Socket.io.

## Структура

```
hush/
  server.js        — весь backend: API + Socket.io
  models.js        — схемы MongoDB (User, Chat, Message, PendingUser)
  mail.js          — отправка кода подтверждения на почту
  package.json
  .env.example
  public/
    index.html
    style.css       — базовые стили без оформления (только layout)
    client.js       — вся логика клиента
```

## Иконка приложения

Положите свой файл в `public/icon.png` (квадратный, например 512×512) —
он подхватится автоматически как логотип на экране входа и как favicon.
Ничего в коде менять не нужно.

## Локальный запуск

```bash
npm install
cp .env.example .env
# заполните MONGODB_URI и JWT_SECRET в .env
npm start
```

Если SMTP не настроен — код подтверждения при регистрации будет просто
печататься в консоль сервера (`[mail:dev] Код подтверждения для ... : 123456`).
Это нормально для разработки и первого теста.

## База данных

Используется MongoDB Atlas — создайте бесплатный кластер на
https://cloud.mongodb.com, добавьте пользователя БД, разрешите доступ с
любого IP (0.0.0.0/0) в Network Access, скопируйте строку подключения в
`MONGODB_URI`.

## Деплой на Render

1. Залейте проект в GitHub-репозиторий.
2. На render.com: **New → Web Service**, подключите репозиторий.
3. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. В разделе Environment добавьте переменные из `.env.example`
   (`MONGODB_URI`, `JWT_SECRET`, при желании `SMTP_*`).
5. Деплой — Render сам подставит `PORT`.

## Что уже есть

- Регистрация: email/пароль → код на почту → выбор аватара, ника и
  юзернейма (от 4 символов)
- Вход по email или юзернейму
- Сжатие аватаров: `sharp` ужимает любое фото до 256×256 webp (quality 75)
  перед сохранением в БД — экономит место и трафик
- Поиск людей, открытие профиля, отправка сообщения из профиля
- Личные чаты, группы, каналы
- Реальное время на Socket.io
